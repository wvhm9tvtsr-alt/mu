# 美容報表管理

依使用者提供的美容報表.xlsx 建立，保留 10 張工作表的資料、合併儲存格與 590 個公式。沿用原表股東月結、代理抽成與護理師人工／時薪／項目金額，不將所有角色改為按售價比例。

## 使用

直接用瀏覽器開啟 preview.html；或在 /workspace/mu 執行 `python -m http.server 8000 --bind 0.0.0.0`。不需安裝依賴。點選儲存格編輯，可輸入文字、數字或公式。支援加減乘除、括號、同工作表參照及 SUM 範圍。修改後自動重算並保存至瀏覽器 localStorage。資料可匯出與匯入 JSON 備份。

## 限制

這是保留原報表結構的第一版，尚無帳號或多人同步。新增列不複製公式或延伸合計範圍。搜尋時暫時展開合併儲存格以避免跨列錯位。盤點與叫貨維持原表的人工紀錄，未自動連動銷售或推算現有库存。人工填寫的金額仍為原值；自動計算只依原有公式。尚不支援匯出 Excel、跨表公式或其他 Excel 函數。

## 驗證

已驗證所有 590 個公式可計算，及成本、售價修改後重算和代理 10% / 5% 抽成。以系統 Chromium 驗證頁籤切換、編輯、重算、重新載入後保存、搜尋、護理師表、新增列與 JSON 匯出。

檔案內含原表資料，請僅提供给有權查看的人員。原始 Excel 保持不變。

## 股東與還款管理

左側分頁前兩頁為股東分成紀錄與代理分成記錄。股東頁提供月度淨利、比例、手動扣款、狀態、日期與備註。分成四捨五入至小數二位，扣款超過分成會顯示股東尚需支付。還款區僅計本金，按借款獨立累計，拒絕超額還款。資料使用獨立 localStorage 鍵 mu-finance-v1，備份亦獨立於原 Excel 資料。原股東 Excel 完整保留於可展開區塊，不自動推算歷史比例或扣款。
