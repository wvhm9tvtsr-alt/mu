# 美容報表管理

依使用者提供的美容報表.xlsx 建立，保留 10 張工作表的資料、合併儲存格與 590 個公式。沿用原表股東月結、代理抽成與護理師人工／時薪／項目金額，不將所有角色改為按售價比例。

## 使用

直接用瀏覽器開啟 preview.html；或在 /workspace/mu 執行 `python -m http.server 8000 --bind 0.0.0.0`。不需安裝依賴。點選儲存格編輯，可輸入文字、數字或公式。支援加減乘除、括號、同工作表參照及 SUM 範圍。修改後自動重算並保存至瀏覽器 localStorage。資料可匯出與匯入 JSON 備份。

## 限制

這是保留原報表結構的第一版，尚無帳號或多人同步。新增列不複製公式或延伸合計範圍。搜尋時暫時展開合併儲存格以避免跨列錯位。盤點與叫貨維持原表的人工紀錄，未自動連動銷售或推算現有库存。人工填寫的金額仍為原值；自動計算只依原有公式。尚不支援匯出 Excel、跨表公式或其他 Excel 函數。

## 驗證

已驗證所有 590 個公式可計算，及成本、售價修改後重算和代理 10% / 5% 抽成。以系統 Chromium 驗證頁籤切換、編輯、重算、重新載入後保存、搜尋、護理師表、新增列與 JSON 匯出。

## 第十分頁：營運分析與每月回訪

上傳 .xlsx 或 CSV（單次 10 MB、最多 100,000 列／200 欄），選工作表、標題列與欄位後檢查，再確認匯入。可加入或取代現有分析，預設按完整原列內容去重，不會把姓名、日期、品項、金額相同但其他原始欄位不同的真實紀錄誤刪。錯誤列與重複列會提示數量與錯誤列號。Excel 使用本機 vendor/exceljs.min.js（ExcelJS 4.4.0，MIT，安裝前依 npm 發布 SHA-512 完整性核對，來源記錄在 vendor/exceljs-source.json），沒有以第三方 CDN 上傳或解析客人檔案。CSV 支援 UTF-8 與 Big5，舊 .xls 需另存 .xlsx。

依已結單、已發生的服務紀錄計消費業績；實收使用付款金額，保留退款負數。儲值、買課程獨立列示，避免與後續服務重複計算，消費金額沿用檔案數字，不再重扣折扣。提供月份、客人數、到店次數、平均每筆紀錄／每次到店／每位客人消費、品項排行、同次到店常見組合、折扣觀察與活動建議。沒有結帳單號時，以同日同客人估算到店，沒有客戶編號時按姓名識別，不能保證同名不同人能區分。歷史成本缺少則不計淨利，不套用今日成本回填舊消費；沒有單項金額時排行是主服務帶動的整筆消費，不能宣稱精確單項收益。只在完整歷史中首見，不等同真正新客；未結束月份不能直接與完整前月判斷成長或衰退。

資料、聯繫標記、品項分類與週期保存在 mu-business-analytics-v1，提供完整 JSON 備份還原；儲存失敗不取代原資料。分析與其他分頁獨立，沒有自動跨裝置同步。使用者上傳到聊天的 Excel 不會被提交到公開網站；正式使用需在自己的瀏覽器上傳一次。已使用使用者提供的 Excel 與合成案例，核對消費、實收、月份、客人與回訪計算。原客戶檔案、真實分析結果及測試資料沒有加入儲存庫。

第七頁提供「文字／回本試算」：貼上有標籤的文字，或讀取本機 TXT／CSV／Markdown 文字檔（UTF-8、Big5、含 BOM 的 UTF-16），可一次核對多個品項。支援逐行「ONDA PRO／全天成本 35,000／每位收費 8,000／預計人數 5」及表格「分類、名稱、數量、成本、定價」；不確定的成本方式或數字會留待補填，衝突數字不猜測。文字以資料處理，不執行其中指令；檔案不傳到伺服器。一次最多 100,000 字元、200 個待核對品項，文字檔上限 1 MB。

每個現有成本方案旁亦可按「回本試算」帶入整份方案成本與定價快照。成本方式分全天共用與每位成本，可選填額外每人耗材或固定廠商費；僅以總收費減廠商成本計算，不扣醫生抽成。皮秒／蜂巢帶入共同全天成本，混合接客可在同一試算新增不同收費組，按各組人數合計而不重複計成本。人數未填時只顯示回本門檻；已填時計算總收費、廠商成本與回本差額。以整數分計算，金額／人數不完整、分數人數或計算超出精確範圍時不儲存。只有按「確認儲存」才寫入獨立的 costsData.breakEvenTrials，不改動原有成本方案、庫存及醫師帳。已存試算可編輯／刪除，最多保存 1,000 份，包含於第七頁完整成本備份；儲存失敗保留原資料與待存試算。
