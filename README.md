# 美容報表管理

依使用者提供的美容報表.xlsx 建立，保留 10 張工作表的資料、合併儲存格與 590 個公式。沿用原表股東月結、代理抽成與護理師人工／時薪／項目金額，不將所有角色改為按售價比例。

## 使用

直接用瀏覽器開啟 preview.html；或在 /workspace/mu 執行 `python -m http.server 8000 --bind 0.0.0.0`。不需安裝依賴。點選儲存格編輯，可輸入文字、數字或公式。支援加減乘除、括號、同工作表參照及 SUM 範圍。修改後自動重算並保存至瀏覽器 localStorage。資料可匯出與匯入 JSON 備份。

## 限制

這是保留原報表結構的第一版，尚無帳號或多人同步。新增列不複製公式或延伸合計範圍。搜尋時暫時展開合併儲存格以避免跨列錯位。盤點與叫貨維持原表的人工紀錄，未自動連動銷售或推算現有库存。人工填寫的金額仍為原值；自動計算只依原有公式。尚不支援匯出 Excel、跨表公式或其他 Excel 函數。

## 驗證

已驗證所有 590 個公式可計算，及成本、售價修改後重算和代理 10% / 5% 抽成。以系統 Chromium 驗證頁籤切換、編輯、重算、重新載入後保存、搜尋、護理師表、新增列與 JSON 匯出。

檔案內含原表資料，請僅提供给有權查看的人員。原始 Excel 保持不變。

## 股東與還款管理

股東頁先顯示姓名清單，點選姓名後只顯示該人的紀錄。新增分成才展開表單，姓名自動帶入；儲存後回到紀錄列表。可新增股東，並依淨利、手填比例及手填扣款計算結算金額。紀錄可編輯、刪除。

還款另設入口，只有初始金額、還款日期、還款金額、剩餘金額，不計息。初始金額可修改，但不得小於已還金額；新增還款後依日期排序計算每筆剩餘本金，拒絕超額還款。舊版多筆借款保留，可用還款紀錄編號切換，舊姓名與備註保留於備份資料但不顯示在簡化畫面。

資料沿用 localStorage 鍵 mu-finance-v1，既有新式分成和還款紀錄直接保留。姓名清單包含已儲存紀錄及原 Excel 月結股東姓名；原 Excel 歷史金額不自動推算，完整資料可在更多功能展開查看。備份功能收納於更多功能，可匯出／匯入含新增股東姓名的 JSON。只在瀏覽器本機保存，不多人同步。

已使用 Chromium 驗證姓名入口、自動帶入、新增／編輯分成、按股東篩選、負數結算、簡化還款、超額還款拒絕、重新載入持久保存、旧版資料兼容、手機與其他分頁。

分成新增「前期」選項：先將總淨利扣成本 50%，再乘比例，分成及最後結算四捨五入為整數元。新增紀錄預設前期，舊紀錄未有 early 欄位時維持不扣 50%。可逐筆切換，依依固定列入股東姓名入口。
