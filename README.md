# 美容報表管理

依使用者提供的美容報表.xlsx 建立，保留 10 張工作表的資料、合併儲存格與 590 個公式。沿用原表股東月結、代理抽成與護理師人工／時薪／項目金額，不將所有角色改為按售價比例。

## 使用

直接用瀏覽器開啟 preview.html；或在 /workspace/mu 執行 `python -m http.server 8000 --bind 0.0.0.0`。不需安裝依賴。點選儲存格編輯，可輸入文字、數字或公式。支援加減乘除、括號、同工作表參照及 SUM 範圍。修改後自動重算並保存至瀏覽器 localStorage。資料可匯出與匯入 JSON 備份。

## 限制

這是保留原報表結構的第一版，尚無帳號或多人同步。新增列不複製公式或延伸合計範圍。搜尋時暫時展開合併儲存格以避免跨列錯位。盤點與叫貨維持原表的人工紀錄，未自動連動銷售或推算現有库存。人工填寫的金額仍為原值；自動計算只依原有公式。尚不支援匯出 Excel、跨表公式或其他 Excel 函數。

## 驗證

已驗證所有 590 個公式可計算，及成本、售價修改後重算和代理 10% / 5% 抽成。以系統 Chromium 驗證頁籤切換、編輯、重算、重新載入後保存、搜尋、護理師表、新增列與 JSON 匯出。

檔案內含原表資料，請僅提供给有權查看的人員。原始 Excel 保持不變。

## 股東與還款管理

「新增月份」一次輸入月份（支援民國 115/5）、總淨利與前期扣成本 50% 選項。同時填寫佑安、依依、小白的比例、扣款金額、扣款說明、正負調整、領取狀態、日期及備註。分成先四捨五入為整數元，再扣款加調整。畫面顯示四捨五入差額及手動調整合計，不自動分配。一次儲存三人的紀錄，月度總比例不得超過 100%；同月份不得重複新增，改用查看／編輯更新。

姓名入口可查看個人紀錄。總金額只顯示一個數字，加總所有紀錄的扣款與調整後結果，包含負數。個人編輯不得單獨改變該月份共享的淨利、月份或前期設定；請透過月份列表修改這些值。

按使用者明確要求，首次開啟月度新版時僅移除當時既有的小白測試分成，其他分成與還款不動。使用同一筆 localStorage 資料的 monthlySetupVersion=1 標記確保不再刪除後續正式小白紀錄；刪除前有測試資料時保存 mu-before-monthly-v1 本機復原副本。原 Excel 不變。新資料仍用 mu-finance-v1，匯入備份保留既有紀錄且標記已完成遷移。讀取既有資料失敗時不自動覆蓋。

還款只顯示初始金額、還款日期、還款金額、剩餘金額，不計息。原有多筆借款保留。資料仍僅存此瀏覽器，更多功能可備份匯出／匯入，沒有多人或跨裝置同步。

驗證：Chromium 實際測試測試資料一次性清除、其他紀錄保留、三人一次儲存、民國年月、扣成本、四捨五入、正負調整、扣款說明、負數總額、重新載入、新資料保留、月份編輯不重複、重複月份阻擋、還款與其他分頁。

## 代理分成記錄

第二分頁資料由使用者手動輸入，不預載 Excel 代理紀錄。代理名字分組顯示，點選姓名即可展開該代理全部明細；也可於群組直接新增並帶入姓名。欄位包括代理、施作日、客人、總金額、可選 5/10/20 或自填的比例、領取狀態。重新載入預設收合姓名清單。可搜尋與篩選，修改、封存、還原及完整備份功能保留。

原表預載紀錄採一次性移除，已手動新增或編輯的紀錄保留。manualEntryVersion=1 標記避免重複清理。移除前有預載資料時，於 mu-agents-before-manual-v1 保存本機復原副本。原始 Excel 不變。

localStorage mu-agents-v1 保存紀錄及歷次修改留檔；JSON 匯出含全部資料與歷史，沒有跨裝置同步。請定期備份。

Chromium 已驗證初始空白、同代理分組、收合／展開、姓名帶入、搜尋、預載清理與手動資料保留、遷移只執行一次。

每位代理展開後显示未領取／已領取抽成總額，依该代理全部未封存紀錄計算，不受搜尋或領取狀態篩選影響。封存模式只加總封存紀錄，未標記者不計入兩個總額。代理頁金額顯示為整數（顯示四捨五入，不改原始金額）；自填比例可保留 7.5% 等小數。已驗證按代理隔離、篩選不改總額、修改領取狀態即更新及封存分開計算。
